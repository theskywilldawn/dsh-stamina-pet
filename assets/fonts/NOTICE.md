# 字体说明

## 内置字体（随插件分发）

**站酷快乐体 2016 修订版** —— `ZCOOLKuaiLe-Regular.ttf`

- 版权方：**站酷（ZCOOL）**，由站酷社区设计师集体创作
- 授权：免费商用，可随软件分发；**不得修改字体文件本身、不得单独售卖字体**
- 出处：<https://www.zcool.com.cn/special/zcoolfonts/>
- 官方声明原文随字体包提供，核心两条：①全体造字者保留署名权；②禁止修改字体文件、禁止单独售卖

选它做 UI 字体，是因为它手写感强、活泼，和小星辰的性格对得上，而且只有 1.59 MB。

## 本地自备字体（**不随插件分发**，默认不存在）

`local/` 子目录留给使用者自己放字体。插件会**优先**尝试加载：

```
local/HKFangYuanW7.ttf    →  font-family: XingchenLocal
```

没有这个文件就静默回退到内置的站酷快乐体（`XingchenKuaiLe`），不报错、不影响使用。

华康方圆体（DynaFont / 华康）是**商业字体**，作者本人在本机自用，但**不随本仓库分发** ——
`local/` 已在 `.gitignore` 与 npm 的 `files` 里排除。要自备请自行向华康取得授权。
